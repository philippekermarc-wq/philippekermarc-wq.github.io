Adhérer à l'Association

La démarche est très simple : l'adhésion est gérée sur le site HelloAsso, qui permet de régler la cotisation annuelle et obtenir sa carte d'ahérent.

Le Festival ayant lieu en début d'année civile (en février le plus souvent), les adhésions enregistrées à partir de Septembre valent pour le Festival de l'année suivante. A partir du 1/9/26, l'adhésion est donc "Adhésion 2026-2027" sur le site HelloAsso.

Faire un don à l'Association

La démarche est très simple : votre don est géré sur le site HelloAsso, qui permet de verser la somme que vous souhaitez et obtenir le justificatif correspondant à prendre en compte dans votre déclaration de revenus de l'année.

Réserver un billet

Pour les concerts organisés par l'Association Mardi Graves, la billetterie est gérée sur le site HelloAsso.

Pour les autres concerts, merci de vous rapprocher de l'oganisateur indiqué dans le programme.

La page sur le Festival 2027 vous donne les informations utiles pour l'inscription aux stages.
